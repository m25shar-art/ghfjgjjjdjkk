# УчительGPT 2.0 — ИИ-помощник для учителей

## Запуск
1. Установите Node.js 20+.
2. Откройте папку в VS Code.
3. Выполните `npm install`.
4. Скопируйте `.env.example` в `.env`, укажите `AITUNNEL_API_KEY`, уникальные `SESSION_SECRET` и `DEV_PANEL_PASSWORD`.
5. Выполните `npm run dev`, затем откройте `http://localhost:3000`.

## Что нового
- Обновлённый адаптивный сине-белый интерфейс.
- Умный чат с историей, поиском, переименованием (двойной щелчок по чату), копированием, повторной генерацией и действиями «Сократить», «Подробно», «Переписать», «Исправить ошибки».
- Инструменты педагога: конспекты, тесты, рабочие листы, сценарии, планы мероприятий и содержание презентаций.
- Создание PDF/DOCX/TXT/PPTX по явному запросу; обычные текстовые просьбы остаются ответом в чате. Экспорт на сервере разрешён только Pro.
- Загрузка учебников PDF/DOCX до 12 МБ и вопросы по извлечённому тексту доступны Plus/Pro. Текст ограничен 60 000 символами; сканированные PDF без текстового слоя не распознаются (OCR отсутствует).
- Поиск моделей, вкладки «Доступные»/«Все модели», описания и ограничения тарифов. GPT-4o Mini удалена; API ID Qwen изменён на `qwen3.7-flash`.
- Plus — 129 ₽/мес.; Pro — 299 ₽/мес.
- Личный кабинет, история чатов, статистика использования и журнал запросов для разработчика.

## Тарифы
- **Free:** Claude Haiku 5.5, GPT 6 Luna, DeepSeek V4.1 Flash, Qwen 3.7 Flash.
- **Plus — 129 ₽/мес.:** модели уровня Plus, а также загрузка учебников PDF/DOCX.
- **Pro — 299 ₽/мес.:** модели Pro, создание PDF/DOCX/TXT/PPTX.

Проверьте точные API ID моделей в каталоге AITunnel: отображаемые названия могут отличаться от идентификаторов API.

## Данные и безопасность
Пароли хранятся как bcrypt-хеши; API-ключ хранится на сервере. Административные маршруты требуют серверной сессии разработчика. Перед публикацией обязательно измените секреты в `.env`, включите HTTPS, настройте rate limiting и постоянное хранилище сессий. Встроенный express-session MemoryStore и JSON-хранилища рассчитаны на небольшой прототип, не на высокую нагрузку.

Пользователи и данные хранятся в `data/users.json`, `data/chats.json` и `data/requests.json`. Панель разработчика: `/developer.html`.

Подпись интерфейса: «Сделано специально для учителей школы „МБОУ „Центр образования „Перспектива““».
